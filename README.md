# Claudewerkplaats


## Oefenomgeving denk- en werkwijzen
- `oefenen/`: de oefenomgeving (ketenpuzzel C21, systeemdiagram C23), havo en vwo.
- `docent.html`: links en embedcodes per onderdeel, met voorbeeldweergave.
  https://bioloognie.github.io/Claudewerkplaats/docent.html

Links kun je samenstellen met `?thema=tryout1&niveau=havo|vwo` en eventueel `&onderdeel=keten|systeem`
(zonder onderdeel: het geheel met menu). `ketenpuzzel.html` stuurt door naar `oefenen/`.
De oefenstof staat in `oefenen/index.html` tussen `OEFENSTOF` en `EINDE OEFENSTOF`.
